# DeepFakeDetector Project

Overview

This project implements a deep learning–based image classification system to detect real and fake (deepfake) images. The system uses a Convolutional Neural Network (CNN) trained on facial image data and incorporates preprocessing, data augmentation, and model optimization techniques to improve classification accuracy.

To enhance model interpretability, Grad-CAM (Gradient-weighted Class Activation Mapping) is used to generate visual explanations that highlight the regions of an image influencing the model’s predictions.

Features:

>> CNN-based real vs fake image classification

>> Image preprocessing and normalization

>> Data augmentation to improve generalization

>> Model tuning for enhanced performance

>> Grad-CAM visualizations for explainable AI

>> Modular and scalable project structure

Technologies Used:

>> Python

>> TensorFlow / Keras (or PyTorch)

>> OpenCV

>> NumPy

>> Matplotlib

>> Grad-CAM for model interpretability

Working Principle:

>> Input images are preprocessed and normalized.

>> Data augmentation techniques are applied during training.

>> A CNN model is trained to classify images as real or fake.

>> The trained model generates predictions on unseen images.

>> Grad-CAM is applied to visualize important regions contributing to predictions
